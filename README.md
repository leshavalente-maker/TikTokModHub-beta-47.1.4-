# TikTokModHub Beta 1.0.0 (47.1.4)

Модифицированный клиент TikTok с обходом антифрода, встроенными настройками и скачиванием видео без водяных знаков через Telegram-бота.

## Возможности
— Настройки внутри TikTok. 
— Чистый UI. Аккуратные карточки, иконки.
- Настройки внутри приложения.
- Скачивание без вотермарки через @ttmh_download_bot.
