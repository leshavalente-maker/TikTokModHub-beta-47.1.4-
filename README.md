# TikTokModHub Beta 1.0.0 (47.1.4)

Модифицированный клиент TikTok с обходом антифрода, встроенными настройками и скачиванием видео без водяных знаков через Telegram-бота.

## Возможности
— Настройки внутри TikTok. Не нужно скачивать плагины. Все настройки мода встроены прямо в «Настройки Конфиденциальности».
— Чистый UI. Аккуратные карточки, иконки, все как мы любим.
— Обход региональных ограничений. (По умолчанию включена Беларусь) 
— Скачивание без водяных знаков.
